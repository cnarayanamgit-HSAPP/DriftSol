# DriftSol

Enterprise-grade **Data Drift, Semantic Drift & AI Drift Handling Platform**.

## Current Pilot
- **Domain**: Healthcare
- **Use Case**: Readmission Prediction

## Structure
- `platform/` → Shared core platform (reusable across domains)
- `domains/` → Domain & use-case specific implementations
- `applications/` → Deployable APIs, UIs and services
- `infrastructure/` → Docker, Kubernetes, local development
- `test_harness/` → Comprehensive testing framework
